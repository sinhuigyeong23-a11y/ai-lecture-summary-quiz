# AI 강의 내용 요약 및 퀴즈 생성 웹서비스

## 1. 프로젝트 소개

본 프로젝트는 AI를 활용하여 강의 자료를 요약하고, 학습 내용에 대한 퀴즈를 자동으로 생성하는 웹서비스입니다.

긴 강의 자료를 읽고 직접 정리해야 하는 불편함을 줄이고, 퀴즈를 통해 학습 내용을 쉽게 복습할 수 있도록 제작합니다.

## 2. 프로젝트 목적

- 강의 자료를 효율적으로 요약하기
- AI를 활용하여 학습용 퀴즈 자동 생성하기
- 퀴즈 풀이를 통해 학습 내용을 복습하기
- 학습에 필요한 시간과 노력을 줄이기

## 3. 주요 기능

### 1) 강의 자료 업로드
사용자가 강의 자료 파일을 업로드할 수 있습니다.

### 2) AI 강의 내용 요약
업로드한 강의 자료에서 중요한 내용을 추출하고 핵심 내용을 요약합니다.

### 3) AI 퀴즈 생성
강의 자료의 내용을 바탕으로 학습용 퀴즈를 생성합니다.

### 4) 퀴즈 풀이 및 결과 확인
사용자는 생성된 문제를 풀고 정답 여부와 해설을 확인할 수 있습니다.

## 4. 주요 사용자

- 강의 자료를 빠르게 정리하고 싶은 대학생
- 시험을 준비하며 학습 내용을 복습하고 싶은 학생
- 강의 내용을 바탕으로 연습 문제를 만들고 싶은 학습자

## 5. 서비스 이용 과정

1. 웹사이트에 접속합니다.
2. 강의 자료 파일을 업로드합니다.
3. AI가 강의 내용을 요약합니다.
4. 요약 내용을 확인하고 퀴즈 생성을 요청합니다.
5. 생성된 퀴즈를 풀고 정답과 해설을 확인합니다.

## 6. 개발 환경

- Frontend: 구현 기술 및 사용 도구 기입
- Backend: 구현 기술 및 사용 도구 기입
- AI: 사용할 AI 모델 또는 API 기입
- Version Control: Git, GitHub

※ 실제로 사용한 기술과 도구를 기준으로 작성합니다.

## 7. 개발 일정

- 1주차: 기획 및 요구사항 분석
- 2주차: UI/UX 디자인 및 프론트엔드 구현
- 3주차: 자료 업로드 및 백엔드 구현
- 4주차: AI 요약 및 퀴즈 생성 구현
- 5주차: 퀴즈 풀이 기능 구현
- 6주차: 기능 연동 및 테스트
- 7주차: 문서 작성 및 GitHub 정리
- 8주차: 최종 점검 및 발표 준비

## 8. 기대 효과

본 서비스는 강의 자료 정리 시간을 줄이고, AI가 생성한 퀴즈를 통해 사용자가 학습 내용을 반복적으로 복습할 수 있도록 돕습니다. 이를 통해 보다 편리하고 효율적인 학습 환경을 제공하는 것을 목표로 합니다.
